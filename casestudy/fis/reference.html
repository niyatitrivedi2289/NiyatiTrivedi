Cancellation

Cancel a previously authorized payment before it has been captured for settlement.

POST /payments/authorizations/{authorizationId}/cancellations

Methods

Responses

202 Accepted The cancellation request has been accepted.
400 Bad Request The request body or path parameter was malformed.
409 Conflict The authorization has already been settled or cancelled.
