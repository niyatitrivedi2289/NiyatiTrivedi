    Get started

    Five steps from sandbox to live.

    A predictable path with clear ownership at each stage. Most teams reach a test transaction inside an afternoon.

    1. 1
      Obtain Worldpay credentials
      Talk to your Implementation Manager to issue sandbox keys.
    2. 2
      Query root resources
      Discover available actions via hyper-media links.
    3. 3
      Choose your API
      Authorize, verify, tokenise or settle.
    4. 4
      Submit your request
      Use any HTTPS-capable client. JSON in, JSON out.
    5. 5
      Plan your go-live
      Move from sandbox to production with a single header change.
