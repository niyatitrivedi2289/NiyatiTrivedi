# Niyati Trivedi — Portfolio

A static site with no build step. Put the **contents** of this folder at the root of the GitHub repo. `index.html` must be at the top level.

Case-study pages use root paths (`/casestudy/...`), so they load whether or not the address ends in `/`. The site must be served from the domain root (Vercel default).

- `/`: home
- `/casestudy/fis/`: FIS Developer Experience, plus the prototypes `landing.html`, `apis.html`, `reference.html`, `documentation.html` and `search-results.html`
- `/casestudy/health/`: CardioNexion
